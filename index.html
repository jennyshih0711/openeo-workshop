ABOUT THE WORKSHOP

從平台操作到空間分析實作

國家實驗研究院國家高速網路與計算中心（NCHC）致力於推動雲端遙測資料分析服務，透過「國土治理數據整合平台」，提供以標準化介面存取與分析多來源遙測影像的實作環境。

平台導入 openEO 開源技術架構，讓研究人員、開發者與決策者能透過統一的 API 介面，存取並分析來自不同衛星、感測器及資料中心的遙測資料，提升資料應用與分析效率。學員將在課程中認識平台操作介面與基礎分析流程，實際體驗影像存取、指標計算及分析成果視覺化等應用。

本次工作坊邀請金門大學學生共同參與，透過課程講解與實際操作，協助學員掌握基礎影像處理知識，並學習運用平台完成分析任務。活動安排分組實作與成果報告，期待促進地理空間資料在國土治理與決策支援領域的實務交流與合作。
